name: Response style
description: Terse responses, no trailing summaries
type: feedback
---

User wants terse responses with no trailing summaries.

**Why:** "I can read the diff" — they find the end-of-turn recap redundant.

**How to apply:** End turns with one or two sentences at most. Skip the
"I did X, Y, Z" wrap-up block unless something non-obvious needs flagging.
